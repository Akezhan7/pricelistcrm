### ✅ 2. Backend - Контроллер заявок

**Файл:** `server/controllers/orderController.js`

**Реализованные методы:**

#### `getOrders(req, res)`
- Получение списка всех заявок с фильтрацией и пагинацией
- Фильтры: статус, статус оплаты, поставщик, даты, поиск по номеру
- Статистика по всем заявкам (количество в каждом статусе, суммы)
- Eager loading поставщика и создателя заявки

#### `getOrderById(req, res)`
- Получение детальной информации о заявке
- Включает: поставщика, создателя, товары с продуктами, историю статусов

#### `createOrder(req, res)`
- Создание новой заявки с товарами
- Автогенерация номера заявки в формате `ORD-YYYY-NNNN`
- Валидация существования поставщика и товаров
- Автоматический расчет общей суммы
- Создание первой записи в истории статусов
- Транзакция для атомарности операции

#### `updateOrder(req, res)`
- Обновление заявки (только в статусе "В работе")
- Изменение даты поставки, места доставки, комментариев
- Обновление списка товаров с пересчетом суммы
- Валидация и транзакции

#### `changeOrderStatus(req, res)`
- Смена статуса заявки с проверкой правил перехода
- Правила переходов:
  1. "В работе" → "На точке" (admin, purchase_manager)
  2. "На точке" → "В пути" (admin, purchase_manager, driver)
  3. "В пути" → "На складе" (admin, warehouse_operator, driver)
- Нельзя вернуться на предыдущий статус
- Создание записи в истории с комментарием

#### `deleteOrder(req, res)`
- Мягкое удаление заявки (isActive = false)
- Можно удалить только в статусе "В работе" и "Не оплачено"
- Только для администратора

**Особенности:**
- Использование транзакций для целостности данных
- Подробные сообщения об ошибках
- Валидация бизнес-правил
- Оптимизированные SQL запросы с JOIN

## 💡 Особенности реализации

### Генерация номера заявки
```javascript
// Формат: ORD-YYYY-NNNN
const generateOrderNumber = async () => {
  const year = new Date().getFullYear();
  const prefix = `ORD-${year}-`;
  const lastOrder = await Order.findOne({
    where: { orderNumber: { [Op.like]: `${prefix}%` } },
    order: [['createdAt', 'DESC']]
  });
  let nextNumber = lastOrder ? parseInt(lastOrder.orderNumber.split('-')[2]) + 1 : 1;
  return `${prefix}${String(nextNumber).padStart(4, '0')}`;
};
```

### Правила смены статусов (диаграмма)
```
┌──────────────┐      ┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│  В работе    │─────►│   На точке   │─────►│    В пути    │─────►│  На складе   │
└──────────────┘      └──────────────┘      └──────────────┘      └──────────────┘
     admin                admin                driver               warehouse_op
     purchase_mgr         purchase_mgr         purchase_mgr         driver
                          driver               admin                admin
```

### Права доступа по действиям
```
Создание заявки:      admin, purchase_manager
Редактирование:       admin, purchase_manager (только "В работе")
Удаление:             admin (только "В работе" + "Не оплачено")
```
