# ⚡ БЫСТРОЕ ИСПРАВЛЕНИЕ - Проблема с дублированием рынков

## ❌ Проблема
При удалении рынка и попытке создать новый с тем же названием возникала ошибка:
```
SequelizeUniqueConstraintError: markets_name_unique
```

## ✅ Решение применено!

### Что было исправлено:
1. ✅ Удален старый уникальный индекс `markets_name_unique`
2. ✅ Используется частичный индекс (только для активных рынков)
3. ✅ Обновлена модель Market
4. ✅ Улучшена логика контроллера (регистронезависимое сравнение, trim)
5. ✅ Добавлен метод восстановления деактивированных рынков

### Как использовать:

**1. Создать рынок:**
```bash
POST /api/markets
{
  "name": "Ялянь",
  "description": "Описание"
}
```

**2. Удалить рынок (мягкое удаление):**
```bash
DELETE /api/markets/3
```
Рынок станет неактивным (is_active = false)

**3. Создать снова с тем же названием:**
```bash
POST /api/markets
{
  "name": "Ялянь",
  "description": "Новое описание"
}
```
**ТЕПЕРЬ РАБОТАЕТ! ✅**

**4. Или восстановить старый:**
```bash
POST /api/markets/3/restore
```

## 🎯 Технические детали

**Частичный уникальный индекс:**
```sql
CREATE UNIQUE INDEX markets_name_active_unique 
ON markets (name) 
WHERE is_active = true;
```

Это позволяет:
- ✅ Один активный рынок с каждым названием
- ✅ Любое количество неактивных с одинаковыми названиями
- ✅ Переиспользование названий после деактивации
