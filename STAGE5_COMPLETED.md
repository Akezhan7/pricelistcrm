1. **При редактировании товара**

   - "Ручное обновление через редактирование товара"
   - "Обновление через заявку [номер]"

1. **Фильтрация**

   - Текущие цены обоих типов
   - Первые зафиксированные цены
   - Изменение в тенге
   - Изменение в процентах
   - Индикаторы роста/падения

3. **Детали изменения**
   - Тип цены (цветовой бейдж)

   - Процент изменения

   - Разница в тенге (крупным шрифтом, цветовая индикация)
   - Автор изменения
   - Дата и время
   - Связанная заявка (с номером)
   - Причина изменения

### Аналитика (API готово, UI опционально)

1. **Товары с наибольшим количеством изменений**

1. **Массовое обновление**

## 🚀 API Endpoints

### 1. Получить историю цен товара
```http
GET /api/products/:productId/price-history
```

**Query параметры:**
- `priceType` (optional) - 'costPrice' или 'sellingPrice'
- `dateFrom` (optional) - дата начала
- `dateTo` (optional) - дата окончания
- `page` (optional) - страница (по умолчанию: 1)
- `limit` (optional) - количество (по умолчанию: 50)

**Ответ:**

### 4. Обновить базовые цены товаров через заявку
```http
PATCH /api/orders/:id/update-prices
```

**Тело запроса:**
```json
{
  "priceUpdates": [
    {
      "productId": 1,
      "newCostPrice": 5500,
      "newSellingPrice": 7500,
      "reason": "Повышение цен поставщиком"
    },
    {
      "productId": 2,
      "newCostPrice": 3200
    }
  ]
}
```

**Ответ:**
```json
{
  "success": true,
  "data": {
    "order": {
      "id": 5,
      "orderNumber": "ORD-2025-0005"
    },
    "updatedProducts": [
      {
        "id": 1,
        "name": "Товар А",
        "article": "ART-001",
        "oldCostPrice": 5000,
        "newCostPrice": 5500,
        "oldSellingPrice": 7000,
        "newSellingPrice": 7500
      }
    ]
  },
  "message": "Успешно обновлены цены для 1 товаров"
}
```

**Доступ:** admin, purchase_manager

## 🔄 Автоматизация

### Что происходит автоматически

1. **При редактировании товара (PUT /api/products/:id):**
   - Сравнение старых и новых цен
   - Создание записи в PriceHistory для каждой изменённой цены
   - Фиксация пользователя и времени
   - Причина: "Ручное обновление через редактирование товара"

2. **При обновлении через заявку (PATCH /api/orders/:id/update-prices):**
   - Создание записей для всех изменённых цен
   - Связь с заявкой (orderId)
   - Пользовательская причина или автоматическая
   - Возврат списка обновлённых товаров

3. **При запросе истории:**
   - Автоматический расчёт статистики
   - Подсчёт процентов изменения
   - Сортировка по дате (от новых к старым)
   - Пагинация для больших списков
