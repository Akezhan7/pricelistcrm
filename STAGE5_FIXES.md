## 🐛 Найденные проблемы

### 1. **История цен не сохранялась**
**Проблема:** При редактировании товара записи в PriceHistory не создавались.

**Причина:** В `productController.js` старые цены сохранялись **ПОСЛЕ** обновления товара, когда они уже были перезаписаны новыми значениями.

**Код ДО исправления:**
```javascript
const costPriceChanged = costPrice !== undefined && parseFloat(costPrice) !== parseFloat(product.costPrice);
await product.update(updateData); // <-- Сначала обновляли
await createPriceHistoryRecord({
  oldPrice: product.costPrice, // <-- Потом брали уже новую цену!
  newPrice: costPrice,
  // ...
});
```

**Код ПОСЛЕ исправления:**
```javascript
// Сохраняем старые цены ДО обновления
const oldCostPrice = parseFloat(product.costPrice);
const oldSellingPrice = parseFloat(product.sellingPrice);

// Проверяем изменения
const costPriceChanged = costPrice !== undefined && parseFloat(costPrice) !== oldCostPrice;

// Обновляем товар
await product.update(updateData);

// Создаём историю с сохранёнными старыми ценами
await createPriceHistoryRecord({
  oldPrice: oldCostPrice, // <-- Используем сохранённую старую цену
  newPrice: costPrice,
  // ...
});
```

✅ **Результат:** Теперь каждое изменение цены правильно фиксируется в истории.

## 📝 Инструкция по использованию

### Сценарий 1: Просмотр истории цен

1. Открыть Dashboard
2. Найти товар в списке
3. Нажать кнопку 📈 (первая оранжевая иконка)
4. Изучить статистику и историю изменений
5. При необходимости отфильтровать по типу цены

### Сценарий 2: Ручное изменение цены

1. Открыть товар
2. Нажать "Редактировать"
3. Изменить себестоимость или цену продажи
4. Сохранить
5. **Автоматически создаётся запись** в PriceHistory:
   - Старая цена → новая цена
   - Автор изменения
   - Время
   - Причина: "Ручное обновление через редактирование товара"

### Сценарий 3: Обновление цен через заявку

1. Открыть детальную страницу заявки
2. Нажать кнопку "Обновить цены товаров" (фиолетовая)
3. В модальном окне:
   - Выбрать товары для обновления (чекбоксы)
   - Ввести новые цены ИЛИ нажать "Применить цену из заявки"
   - При необходимости изменить глобальную причину
   - Нажать "Обновить"
4. Цены обновляются, создаются записи в истории
